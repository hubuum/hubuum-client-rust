# Hubuum Rust client

Build Rust applications with typed resource IDs, query builders, pagination, and
background-task helpers. Choose an asynchronous or blocking client to fit your
application.

## Start here

- [Install and make your first request](getting-started.md).
- [Configure clients and transports](client-setup.md).
- [Query and paginate resources](querying.md).
- [Check supported server versions](compatibility.md).

## Common workflows

Use [scoped tokens](scoped-auth.md) to limit access, handle
[credential approvals](credential-approvals.md), and follow
[exports and asynchronous tasks](exports-and-tasks.md). The
[API reference](https://docs.rs/hubuum_client/{version}/hubuum_client/) documents
individual types and methods.

This library connects to the [Hubuum server](https://hubuum.github.io/hubuum/).
The [ecosystem home](https://hubuum.github.io/) connects the server, CLI, frontend,
and Python client. Projects release independently; consult compatibility evidence
for the client version you deploy.
